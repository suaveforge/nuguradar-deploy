PHOTO FILTER LAB · LOCAL ENGINE

필터는 하나지만,
사진은 하나가 아니다.

Lightroom에서 사진작가가 다루는 핵심 색보정 요소를 로컬 Filter Manager와 렌더링 엔진으로 옮기는 실험. HSL, Tone Curve, Noise Reduction, 3D LUT, Preset까지 같은 파이프라인 안에서 다룬다.

인터넷 없이 매장 PC에서사진 + Filter ID를 넘기면 로컬 엔진이 같은 룩을 재현하는 구조. AI 생성이 아니라 픽셀 기반 보정 파이프라인을 기본으로 둔다.

Lightroom식 기본 엔진

사진작가가 익숙한 보정 단위를 그대로 분리해 저장하고, 최종적으로 하나의 Preset과 LUT로 묶는다.

기본 톤 · WB / Tint

노출, 대비, Highlight, Shadow, 색온도와 Magenta/Green 균형.

HSL

Red·Orange·Yellow·Green·Aqua·Blue 등 색 영역별 Hue, Saturation, Luminance.

Tone Curve

암부·중간톤·하이라이트를 곡선으로 제어해 필름 룩과 대비를 만든다.

Noise Reduction

저조도에서 생기는 입자를 줄이되 얼굴과 머리카락 디테일은 최대한 유지.

3D LUT (.CUBE)

색→색 변환을 LUT 파일로 고정해 여러 키오스크에서 같은 결과를 재현.

JSON Preset · Preview

설정값 저장/수정/삭제, Before/After 확인, Filter ID 기반 호출까지 연결.

고정 필터 하나에서 생기는 품질 편차

촬영 환경이 같아도 피사체의 피부톤·색 분포가 달라지면 같은 HSL과 Curve가 서로 다르게 보일 수 있다.

A · 필터가 잘 맞는 경우같은 Filter A

밝은 웜톤 기준으로 만든 프리셋에서는 피부가 정돈되고 따뜻한 분위기가 자연스럽게 살아난다.

B · 같은 필터가 덜 맞는 경우같은 Filter A

같은 값을 그대로 쓰면 피부가 뜨거나 회베이지·주황 쪽으로 밀리고 얼굴 입체감이 약해질 수 있다.

핵심: 필터 엔진 구현 자체보다 어려운 건 “모든 피사체에 하나의 고정 Preset을 적용해도 항상 예쁜가”다. 그래서 결과를 매번 다시 튜닝하는 대신, 검수된 타입을 몇 개로 나누는 편이 운영상 단순하다.

해결 제안 · 3+1 고정 Preset

사진작가가 같은 브랜드 분위기로 3~4개 세트를 미리 만든다. 촬영 후에는 밝기와 색 상태만 보고 가장 잘 맞는 세트 하나를 골라 그대로 적용한다.

TYPE 1

밝은 톤용

밝은 영역의 Highlight 보호와 Red/Orange 제어를 중심으로, 깨끗하고 따뜻한 결과를 유지.

TYPE 2

중간 톤용

기본 프로필. 중간 밝기와 중성 색 분포를 기준으로 브랜드 룩을 그대로 재현.

TYPE 3

어두운 톤용

암부 대비와 피부 명도를 보존하고 Orange 밝기 과상승과 채도 손실을 줄이는 타입.

TYPE 4 · SAFE

무난한 기본형

경계가 애매하거나 혼합 조명일 때 쓰는 약한 프로필. 과보정 실패를 막는 안전 타입.
