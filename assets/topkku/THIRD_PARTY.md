# Topkku third-party vector assets

The SVG files in this directory are vendored from the Unicode-organized mirror
`shuding/fluentui-emoji-unicode`, which contains Microsoft Fluent Emoji artwork.

Upstream artwork: https://github.com/microsoft/fluentui-emoji
Unicode-organized source: https://github.com/shuding/fluentui-emoji-unicode
License: MIT. See `LICENSE-Fluent-Emoji.txt`.

NUGU RADAR keeps these files local so Topkku rendering and PNG export do not
depend on a third-party CDN at runtime.
