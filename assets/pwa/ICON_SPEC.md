# NUGU RADAR PWA icon handoff

The PWA shell is prepared, but the final brand icon is intentionally not committed yet.

When the approved icon arrives, add these files here:
- icon-192.png — 192×192, PNG
- icon-512.png — 512×512, PNG
- maskable-512.png — 512×512, PNG with safe content inside the central ~80%
- apple-touch-icon.png — 180×180, PNG

Then update `frontend/manifest.webmanifest` with the 192/512/maskable icon entries and add `apple-touch-icon.png` to app-page heads.

Do not stretch a small source image to make these sizes. Use the approved master artwork.
